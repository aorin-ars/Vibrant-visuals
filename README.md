# Vibrant Visuals

**日本語** | [English](README.en.md)

Minecraft Java Edition 向けの遅延レンダリング（deferred）シェーダーパックです。
**エンティティが「丸影」ではなく、モデルそのものの形の影を落とす**ことを中心に組んであります。

列車・船・航空機のようにカスタムモデルを持つ Mod のエンティティでも、
地形とまったく同じ計算でシャドウマップに描かれるため、
車体の形・窓の抜け・台車の隙間がそのまま地面の影になります。

---

## 必要環境

| | |
|---|---|
| ローダー | **Iris 1.6 以降**（推奨）または **OptiFine H9 以降** |
| Minecraft | 1.16.5 〜 1.21.x |
| GPU | OpenGL 3.3 以上 |

Iris 推奨の理由は `entityShadowDistanceMul` に対応しているためです（後述）。
OptiFine でも動作しますが、この項目だけは無視されます。

## 導入

1. リリースの zip、または `tools/package.sh` で作った zip を用意する
2. `.minecraft/shaderpacks/` に置く
3. ゲーム内で **設定 → ビデオ設定 → シェーダー** から `VibrantVisuals` を選ぶ

リポジトリを直接使う場合は、`shaders/` フォルダを含むこのフォルダごと
`shaderpacks/` に置いても読み込めます。

## エンティティの影について

### 何が変わるのか

バニラの Minecraft は、エンティティの足元に**平たい楕円のテクスチャ**を貼っているだけです。
どんな形のモデルでも影は同じ楕円で、20 ブロックある車両でもニワトリと同じ影になります。

このパックでは:

- **エンティティをシャドウパスに描画します**
  地形・ブロックエンティティ・エンティティがすべて同じシャドウマップを共有するので、
  影は必ずモデルの輪郭になります。屋根が側面に落とす影のような**自己影**も出ます。
- **バニラの丸影を消します**
  正しい形の影の下に黒い楕円が重なるのを防ぎます（`丸影を隠す` で切り替え可）。
- **半透明を透った光は色を持ちます**
  着色ガラスや色付きの窓を透った光は、遮られるのではなくその色で床に落ちます。
- **接地部は鋭く、離れるほど柔らかく**
  台車が線路に接している所の影は鋭いまま、屋根の張り出しの影はぼけます。

### Mod の車両を登録する

`shaders/entity.properties` を開いて、Mod のエンティティ ID を追記してください。

```properties
# 鉄道車両
entity.4011 = minecraft:minecart minecraft:chest_minecart \
              <modid>:<entity_name> <modid>:<entity_name2>

# 道路・水上
entity.4010 = minecraft:boat minecraft:chest_boat \
              <modid>:<entity_name>
```

ここに登録すると、そのエンティティは**車両マテリアル**として扱われ、
塗装された車体らしい光沢（`車両の光沢` スライダー）と、
大きな剛体向けのシャドウバイアスが適用されます。

> **登録しなくても影は出ます。** 登録は見た目を車両向けに寄せるためのものです。
> 存在しない ID を書いてもログに出るだけで壊れません。

### うまくいかないときは

| 症状 | 対処 |
|---|---|
| 車体に黒い縞模様が出る | `エンティティの影バイアス` を上げる |
| 影が本体から浮いている・離れている | `エンティティの影バイアス` / `影のバイアス` を下げる |
| 遠ざかると影だけ消える | `エンティティの影範囲` を上げる（Iris のみ）。それでも駄目なら `影の描画距離` を上げる |
| 長い編成の後ろの方に影が無い | 同上。`影の描画距離` を編成全長より大きく |
| 影がカクカクしている | `シャドウマップ解像度` を上げる。または `シャドウマップ集中度` を下げて手前と奥の品質を均す |
| 足元に黒い楕円が残る | `丸影を隠す` が有効か確認。無効なら丸影はそのまま出ます |
| 影が出ない | ビデオ設定でシェーダーが有効か、`影の描画距離` が 0 でないかを確認 |

詳しい仕組みは [docs/ENTITY_SHADOWS.md](docs/ENTITY_SHADOWS.md) にあります。

## 駅・車両基地のような場面での推奨設定

画像のような長い編成やホーム上屋のある場面では、次の調整が効きます。

| 項目 | 推奨 | 理由 |
|---|---|---|
| 影の描画距離 | 192〜256 m | 編成全長を覆う必要がある |
| エンティティの影範囲 | 2.0〜3.0 | 長い車両が原点距離のカリングで消えるのを防ぐ |
| シャドウマップ集中度 | 0.40〜0.55 | 手前から奥まで品質を均一に寄せる |
| シャドウマップ解像度 | 2048〜4096 | 窓枠・手すり・パンタグラフを影に出す |
| 車両の光沢 | 0.70〜0.85 | 塗装された車体の艶 |
| 太陽軌道の傾き | -30〜-20° | 一日を通して斜光になり、車体側面に影の表情が出る |

`高` プロファイルがこれに近い設定です。まずは `高` を選んでから微調整するのが早いです。

## 設定項目

ゲーム内のシェーダー設定画面から、日本語表示で調整できます。

| 画面 | 内容 |
|---|---|
| 影 | 解像度・描画距離・フィルタ・柔らかさ・集中度・バイアス・色付きの影 |
| エンティティ・車両 | エンティティ専用バイアス・影範囲・丸影・光沢 |
| ライティング | 太陽光・空の光・ブロック光と色温度・鏡面ハイライト・AO |
| 空・大気 | 太陽軌道・空の彩度・霧・光芒・雲 |
| 水・反射 | 波・反射・屈折・吸収・スクリーンスペース反射 |
| 揺れ | 草花・葉・風の強さ |
| 画質・色調 | トーンカーブ・自動露出・ホワイトバランス・彩度・ブルーム・TAA・シャープネス |

プロファイルは `最低` / `低` / `中` / `高` / `最高` の 5 段階です。

## 開発

シェーダーは Minecraft を起動しなくても検証できます。

```bash
# 全 52 ステージを 4 通りのマクロ構成で glslang にかける
# (include はローダーと同じ方法で解決し、エラー行は元ファイルに戻して表示します)
python3 tools/validate_shaders.py

# 設定項目が GLSL・shaders.properties・各 .lang で食い違っていないか確認
python3 tools/check_options.py

# 配布用 zip を作る
tools/package.sh
```

`glslangValidator` が PATH に無い場合は `--glslang <path>` を渡してください。
[KhronosGroup/glslang のリリース](https://github.com/KhronosGroup/glslang/releases)
にビルド済みのものがあります。

構成の説明は [docs/PIPELINE.md](docs/PIPELINE.md) にあります。
